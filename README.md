## Flujo de trabajo

```bash
git checkout actividad-N      # cambiar a la rama de la actividad
# ...trabajar dentro de la carpeta "Actividad N"...
git add .
git commit -m "Actividad N - descripción"
git push origin actividad-N
```

Al terminar una actividad se fusiona en `main`.
